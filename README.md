# 📊 Sorting Student Data by Marks

## 📌 Project Description

**Sorting Student Data by Marks** is a C programming project designed to store and organize student information based on their marks. The program accepts details such as student name, roll number, and marks, then sorts the student records from **lowest to highest marks**.

This project demonstrates the practical use of **structures, arrays, sorting algorithms, loops, and functions in C programming**. It provides a simple way to understand how student records can be processed and arranged efficiently.

## 🎯 Objectives

- To store student details using structures.
- To accept marks and other student information from the user.
- To sort student records based on their marks.
- To display the sorted student data clearly.
- To understand the practical implementation of sorting algorithms in C.

## ✨ Features

- 👩‍🎓 Stores student name and roll number.
- 📝 Stores marks obtained by each student.
- 🔢 Sorts students according to their marks.
- 📈 Displays records in ascending order.
- 💻 Simple and beginner-friendly C program.
- 🧩 Demonstrates the use of structures and arrays.

## 🛠️ Technologies Used

- **Programming Language:** C
- **Concepts:** Structures, Arrays, Loops, Functions, Sorting
- **Development Environment:** GCC / Code::Blocks / VS Code

## ⚙️ Working Principle

1. The program asks the user to enter the number of students.
2. Student details such as name, roll number, and marks are entered.
3. The records are stored using a structure.
4. A sorting technique is applied to compare the marks of students.
5. Student records are arranged from **lowest marks to highest marks**.
6. The sorted student information is displayed as the final output.
